# 우리끼리 난리 파티 — Online multiplayer starter

## 현재 포함된 실시간 게임
- 방 코드 생성 및 참가 (Socket.IO)
- 최대 6인 대기방 / 방장 시작 / 플레이어 퇴장 처리
- 5라운드 랜덤: 숫자 눈치게임, 반응속도, 초스피드 퀴즈, 밸런스 선택
- 서버에서 점수 계산, 결과/최종 순위 동기화

## 로컬 실행
1. Node.js 18+ 설치
2. 터미널에서 프로젝트 폴더로 이동
3. `npm install`
4. `npm start`
5. 브라우저에서 `http://localhost:3000` 접속

## 인터넷에 공개 배포
이 앱은 Socket.IO 실시간 연결을 유지하는 Node 서버가 필요합니다. 정적 사이트 호스팅(Netlify Drop 등)만으로는 실시간 서버를 운영할 수 없습니다. Node를 지원하는 호스팅에 프로젝트를 배포하고 공개 HTTPS URL을 친구에게 공유해야 합니다. 호스팅 환경은 `npm start`를 실행하고 `PORT` 환경변수를 제공해야 합니다.

## 개발 참고
현재 4종 미니게임을 실제 동작하는 온라인 프로토타입으로 구현했습니다. 제안된 나머지 미니게임(기억력, 폭탄 돌리기, 룰렛 생존, 다른 그림 찾기, 타자 대결, 가위바위보, 그림 퀴즈, 동물 잡기)은 아직 구현되지 않았습니다.
